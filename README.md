# Просмотрщик смет

Десктопное приложение для просмотра строительных смет: открывает форматы Смета.РУ и
обменный формат АРПС, показывает смету в привычном виде печатной формы и сверяет
арифметику. **Только просмотр — файлы не изменяются.**

Приложение появилось из простой ситуации: смета есть, а открыть её нечем — программа,
в которой она сделана, недоступна. Формат при этом читаемый, и для просмотра
достаточно самого файла.

## Что умеет

**Открывает четыре вида файлов** (три реализованы):

| Формат | Что это | Статус |
|---|---|---|
| `.xlsx` | смета, сохранённая из Смета.РУ, форма «Смета 12 гр. по ФЕР» | читается |
| `.sobx` | экспорт объекта из Смета.РУ — ZIP с дампами таблиц БД | читается |
| `.arp` | обменный формат АРПС 1.10 | читается |
| `.xlsx` | входящая ЛСР по Методике 421/пр (ГРАНД-Смета/РИМ) | читается* |

\* раскладка колонок сверена ранее на реальном файле, но конкретного образца для
проверки итоговых чисел в проекте нет — см. «Ограничения» ниже. Формат определяется
автоматически по содержимому файла, не по расширению: `.xlsx` открывается либо как
Смета.РУ, либо как ЛСР в зависимости от того, что внутри.

**Показывает смету деревом** «Раздел → Подраздел → Позиция → ресурсные строки»:
под каждой позицией — зарплата, эксплуатация машин, в том числе зарплата машинистов,
материалы, накладные расходы, сметная прибыль и затраты труда. Разделы сворачиваются,
слева — навигация по разделам и подразделам.

**Сверяет арифметику — там, где есть с чем сверять.** В форме `.xlsx` итог напечатан в
шапке, поэтому сумма позиций сравнивается с ним, и результат показан прямо над таблицей:
расхождение в копейки — норма (шапка округлена до тысяч), заметное расхождение
подсвечивается как предупреждение. В `.sobx` и `.arp` итог документа не хранится вовсе —
там приложение честно пишет, что сверить не с чем, и показывает посчитанную сумму.
Выдавать собственную сумму за «итог документа» и рисовать зелёную галочку было бы
самообманом: это деньги.

**Сравнивает две сметы.** Разные редакции одного объекта могут отличаться единичными позициями. Сравнение показывает добавленные, удалённые и изменённые позиции с
разницей в деньгах, дорогие расхождения — сверху. Отчёт сохраняется в текстовый файл.

**Печатает и выгружает.** Любая открытая смета — независимо от того, из какого файла
она прочитана — выводится в привычном виде печатной формы: «Файл → Экспорт в Excel»,
«Файл → Экспорт в PDF», «Файл → Печать» (Ctrl+P). Так `.sobx` и `.arp`, которые
нечем открыть без сметной программы, превращаются в обычный документ, который можно
отправить и подписать.

**Ещё:** несколько смет вкладками, список недавних файлов, открытие перетаскиванием,
поиск по шифру и наименованию со счётчиком совпадений, фильтры «только расценки» и
«без ресурсных строк», сумма по выделенным позициям в статусной строке, светлая и
тёмная темы.

## Установка и запуск

Нужен Python 3.12 или новее.

```
pip install -r requirements.txt
python -m sv
```

Можно сразу передать файлы:

```
python -m sv смета.xlsx выгрузка.sobx
```

На Windows есть `run.bat`.

## Особенности форматов

Тонкости, на которых легко ошибиться при чтении этих файлов:

* **Единицы измерения денег различаются внутри одного документа.** В шапке печатной
  формы итоги напечатаны в тысячах рублей, в позициях — в рублях. Смешение даёт ошибку
  ровно в тысячу раз, а таблица при этом выглядит правдоподобно.
* **`.sobx` — это ZIP с дампами таблиц**, JSON внутри в кодировке cp1251 без BOM;
  парсить его нужно нестрого, потому что внутри строк встречаются управляющие символы.
  Дробные числа хранятся строкой вида `$40298F5C28F5C28F` — это IEEE-754 double
  big-endian в hex, тогда как целые лежат обычными числами.
* **`.arp` — cp866**, поля разделены `#`, числа с десятичной запятой. Итог позиции в
  файле не хранится и вычисляется как прямые затраты плюс накладные расходы и сметная
  прибыль, начисленные на зарплату с учётом коэффициентов.
* **Одна колонка формы может значить разное** в зависимости от типа строки: в строке
  позиции там коэффициент-выражение, в строке итога — сумма.

## Проверка

```
pip install pytest
set SMETA_VIEWER_XLSX=путь\к\вашей\смете.xlsx
python -m pytest -q
```

Тесты не привязаны к конкретной смете: путь берётся из переменной окружения, без неё
они пропускаются. Проверяется самосогласованность разбора — сходимость суммы позиций
с итогом документа, числовые типы денежных полей, разбор ресурсных строк.

## Ограничения

* Только просмотр: редактирования и записи в форматы Смета.РУ нет.
* Экспорт в Excel даёт форму для чтения и печати, а не файл, который примет сметная
  программа: числа выгружаются как значения, без формул и без служебных таблиц.
* Печать сметы в тысячу позиций занимает несколько секунд, окно на это время ждёт.
* В `.sobx` базисные итоги позиций не хранятся отдельным полем, поэтому колонка
  «Стоимость базисная» для этого формата пуста.
* Итог позиции в `.arp` вычисляется, а не читается, поэтому возможны расхождения в
  копейки из-за округления коэффициентов.
* Итог всего документа хранится только в форме Смета.РУ; для `.sobx` и `.arp` сверка
  суммы позиций с итогом невозможна в принципе — приложение об этом сообщает. У ЛСР
  итог хранится, но включает лимитированные затраты и НДС, а сумма позиций — нет:
  расхождение 15–25 % для этого формата норма, приложение не сравнивает их напрямую.
* НДС и итог с НДС из формы Смета.РУ пока не отображаются.
* **Чтение ЛСР 421/пр не проверено на реальном файле с известными суммами** — в
  отличие от трёх остальных форматов. Раскладка колонок взята из независимо сверенной
  спецификации и покрыта структурными тестами на синтетическом файле, но денежная
  точность на настоящем документе не подтверждена. Если у вас есть образец такого
  файла — откройте issue, это поможет проверить и снять оговорку.
* Поиск перебирает все позиции на каждое нажатие клавиши: на сметах в тысячи позиций
  ввод заметно подтормаживает.
